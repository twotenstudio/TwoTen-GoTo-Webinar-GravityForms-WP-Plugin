Registers Gravity Forms submissions as GoTo Webinar registrants.

== Description ==

A Gravity Forms feed add-on for GoTo Webinar. Connect once with OAuth, then add a feed to any form: pick the webinar, map the registrant fields and custom questions, add conditional logic. Registration results are stored on the entry and available as merge tags.

The plugin updates itself from GitHub releases and has a "Check for updates" button.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/` and activate it (Gravity Forms must be active).
2. Create an OAuth client at developer.goto.com with GoTo Webinar access and add the Redirect URI shown under Forms > Settings > GoTo Webinar.
3. Enter the Client ID and Client Secret, save, and click Connect.
4. Add a GoTo Webinar feed to a form.
